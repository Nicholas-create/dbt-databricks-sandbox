02 · How it's built

Rebuilt from two public sources, every morning.

  1. 06:00 · raw_openrouter.models_daily

    A Databricks job saves OpenRouter's public model catalogue as untouched JSON, appending one snapshot a day.

    Ingest
  2. 07:30 · dbt build --target prod

    dbt cleans both sources, matches OpenRouter listings to Epoch AI's notable models and builds the marts. Data tests and a freshness check gate every run.

    Model
  3. select … from rpt_models_latest_price

    A short script reads one tested mart and writes the small JSON file this page loads. No logic lives here.

    Export
  4. github-pages · static files

    GitHub Actions publishes the page. Your browser never talks to the warehouse, so there's no server and no credential to leak.

    Publish
